Project Fog

Fog Shader

Project Overview

Implemented exponential fog in GLSL (OpenGL ES 3.0), using view-space distance to add depth to a textured 3D scene.

Tasks Completed

  • Wrote vertex and fragment shaders targeting OpenGL ES 3.0
  • Implemented exponential fog with a distance- and density-based attenuation model
  • Applied model, view, and projection transforms for view-space fog calculations
  • Debugged an incorrect fog result caused by a missing model transform
  • Sampled textures with sampler2D and blended surface and fog colors

Reflection

The initial fog moved incorrectly because the view transform was applied without the model transform. Finding and fixing that bug strengthened my understanding of coordinate spaces and made the visual result a concrete shader-debugging case study.
