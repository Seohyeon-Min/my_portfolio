ThinkThink! Rhythm Challenge

Role

Project Lead (Game Design, Production, UI)

Tools

Unity, HLSL, C#, GitHub

Problem

A mobile rhythm-puzzle game needed its core design, production coordination, and a Google Play release — plus a way to style UI (rounded buttons, gauges, cards) without hand-making art for every shape.

What I Built

  • Wrote the game design: rhythm-based card matching and a BPM-driven difficulty curve
  • Coordinated development priorities and task requests with the developer
  • Registered and released the game on Google Play Console
  • Built a reusable Unity URP UI shader system (UIStyle.shader + UIStyle.cs) with 9 style groups (rounded corners, shadows, gradients, material presets, noise, edge lines) editable live in the Inspector, packaged as a .unitypackage

Result

Shipped on Google Play; the UI shader system was reused and extended directly in Street Typer's card-combat UI.
