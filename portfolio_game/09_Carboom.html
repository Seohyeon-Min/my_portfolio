Carboom

(IN PRODUCTION / UNFINISHED — LOWER CONFIDENCE) This project is still being built; the summary below describes ongoing work, not a finished shipped project. Key point for anyone skimming this project: the centerpiece here is an artist-facing editor tool (not a personal script) — built so the team's two artists can compose the space background themselves, without touching code.

Role

Gameplay Programmer / Technical Art — Tools

Tools

Unreal Engine, Python (Unreal Editor scripting), C++, Perforce, Jira

Problem

The space background is only ever seen from one fixed point (the arena), so a random 3D scatter of planets produced uneven, unbalanced skies — real 3D distance doesn't match what actually reads on screen. Hand-placing every planet doesn't scale, and I wanted the two artists on the team to be able to compose the sky themselves — tuning counts, sizes, and distances — without touching Python or waiting on me. The team also needs gameplay core systems and a demolition/destruction system for level objects.

What I Built

An artist-facing editor tool, not a one-off script: every knob an artist would want to turn — how many planets, how big, how far, how tightly clustered — lives in a plain Unreal DataAsset they edit directly in the editor, with no code required. One click generates the sky; one click clears it and re-rolls it, so artists can iterate on composition themselves.

  • Artist-tunable DataAsset (ScaleZones) exposing count/scale/distance ranges per zone — the tool reads it, artists own it
  • Places background planets by apparent size, on-screen spacing, and local density — computed as angles/solid angle from the arena, not raw 3D position, so what artists see in the DataAsset matches what actually reads on screen
  • Automatic small-planet clustering with a leader/follower size hierarchy, replacing an earlier version that clumped unevenly or looked uniform
  • A ring-constrained placement rule so accessory "moon" planets stay visible from the arena instead of hiding behind their parent
  • One-click generate/clear workflow (idempotent, label-prefixed spawns) so artists can re-roll the sky without engineering help
  • A demolition/destruction system for destructible level objects
  • Gameplay core systems
  • Collaborating with 2 artists on the game's visuals

Result

In progress — no finished build yet. The placement tool itself is functional, in active use by the team's artists, and iterated in-editor based on their feedback (see the full case study and source on this page). Check back for updates as the project moves out of production.
