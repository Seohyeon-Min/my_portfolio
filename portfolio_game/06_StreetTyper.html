Street Typer

Role

Art · Technical Art · Producer (Team Project)

Tools

C#, Unity, Spriter Pro, 2D Rigging, Animation, HLSL, Clip Studio Paint, GitHub

Problem

Wanted to prove a typing-combat game concept — fighting by typing words quickly and accurately — was actually fun before committing a team to it, then produce a finished build inside a 10-day scope.

What I Built

  • Prototyped the core typing-combat loop myself to validate the idea before pitching it to the team
  • As Producer/Technical Art, owned visual direction, 2D art, UI shaders, VFX, animation, and moment-to-moment feedback across the full 10-day production
  • A deck-building system lets players collect cards through combat and shape their own build

Result

Shipped a playable build, published on itch.io, with a Steam release in progress.
