Ruin Forge — Procedural Ruined-Wall Tool

(IN PRODUCTION / UNFINISHED) Personal Blender 5.2 Geometry Nodes project, still in progress. Authorship, stated explicitly: I set the goal and iteration direction and directly authored the Boolean-based crack-space generation and the surrounding-crack logic. The rest of the implementation (two-stage brick damage, mortar cleanup, clipping, optimization), the renders, and validation were completed with AI assistance.

Role

Technical Artist — Procedural Tools (solo, AI-assisted)

Tools

Blender 5.2 (Geometry Nodes), Python

What the tool does

Environment artists place one control object (DamageCtrl) and adjust modifier values to generate concrete shell damage, cracks along the broken edge, and collapsed brickwork behind it, instead of hand-modeling each ruined wall.

How it works

  • Two layers, one-way data: WallOut (concrete) and WallIn (brick) are separate objects; WallIn reads WallOut's damage values through mesh attributes and Attribute Statistic, so there is no circular reference.
  • Cracks from the real break: a Manifold Boolean cuts WallOut, Intersecting Edges extracts the actual cut boundary, and dot products plus a Raycast keep only concave corners as crack starts.
  • Two-stage brick damage: whole bricks are removed first, then only boundary bricks are fractured for the cross-section.
  • Validation: 0 non-manifold edges; about 116k → 30k vertices after hidden-brick and mortar cleanup; z-fighting removed.

Artist controls

Damage Size, Crack Probability / Threshold / Size, Voronoi Radius / Cell Size / Jaggedness, Inner Break Influence / Depth, Brick Jitter, Break Irregularity, Seed, and Mortar Keep, exposed in the modifier panel.

Limits and next steps

Currently assumes a planar wall facing local +X. Next: sampled surface normals for curved and side-facing walls, the outer wall exposed as a modifier input for reuse, and texture/normal-map materials for broken surfaces.
