Ruin Forge — Procedural Ruined-Wall Tool

(IN PRODUCTION / UNFINISHED) A personal Blender Geometry Nodes project, still in progress. This portfolio page documents the current rendered and verified tool output; curved-surface support, reusable wall references, and final material work remain planned. Authorship: the project owner defined the target behavior, supplied iterative direction, reviewed the output, and authored some nodes. AI assistance completed substantial portions of implementation, rendering, validation, and node integration.

Contribution

Tool direction, iteration requests, review, and selected Geometry Nodes

Tools

Blender 5.2 (Geometry Nodes), Python

Problem

Environment artists building ruined or battle-damaged walls hand-model every break and crack, over and over. The goal is damage that reads like real concrete — a thin outer layer flaking away like an eggshell to reveal the wall underneath — instead of round holes or stamped, repeating patterns.

Current tool output

  • Two-layer wall (WallOut / WallIn) with damage placed by a control object (DamageCtrl, Object Info in Relative mode, so it follows the wall)
  • Irregular cutters (noise-displaced curve → Curve to Mesh → Mesh to Volume → Volume to Mesh) cut into the outer wall with Mesh Boolean (Difference)
  • Real break boundary extracted from the Manifold Boolean's Intersecting Edges via Mesh to Curve selection
  • Corner detection: neighbor directions compared with a dot product, sharp points stored as a "corner" attribute, a random subset grows cracks
  • Zigzag cracks: instanced 12-segment template, index-parity alternating offsets with randomized bend and spacing, tapered diamond-section sweep for a V-groove
  • Topology fix: crack cutters merged via volume remesh and cut with the Manifold solver — 0 non-manifold edges

Artist controls

Damage Size, Crack Probability / Threshold / Size, Voronoi Radius / Cell Size / Jaggedness, Inner Break Influence / Depth, Brick Jitter, Break Irregularity, Seed, and Mortar Keep are exposed through the modifier panel.

Next steps

Replace the fixed local axis with sampled surface normals for curved and side-facing walls; expose the referenced outer wall as a modifier input; strengthen broken surfaces with texture and normal-map materials.
