Double Hit

Role

Systems Programmer · Art/Audio · Production Lead

Tools

C++, GLSL, OpenGL, Spriter Pro, Clip Studio Paint, GitHub

Problem

DigiPen CS230's course engine needed a real sprite/texture/collision pipeline built on top of its GameObject/Component skeleton, plus a hardcoded ~30-platform level layout that required recompiling C++ for any change.

What I Built

  • Wrote the sprite-file parser (textures, animation frames, hotspots, collision shapes)
  • Built a filename-keyed texture cache with dedup
  • Implemented the GameObjectManager's per-frame update/draw/collision-dispatch loop
  • Built a PlatformManager parsing a custom .plf level-data format to replace hardcoded platform coordinates

Result

Systems supported a shipped two-player co-op game and became the direct foundation later expanded into MANZO's renderer, collision, and engine systems.
